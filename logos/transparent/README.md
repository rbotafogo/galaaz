# Transparent Galaaz logo masters

True RGBA PNGs derived from files in the parent `logos/` directory
(white / checkerboard / dark-panel backgrounds removed).

**Keep brand masters here.** Do **not** dump the whole set into `sty/`.

| Location | Role |
|----------|------|
| `logos/` | Original exports (may have opaque backgrounds) |
| `logos/transparent/` | Transparent masters for web, slides, overlays |
| `sty/galaaz-header.png` | Small header-only mark for PDF (`galaaz.sty`) |

Regenerate from parent originals if you replace source artwork.
